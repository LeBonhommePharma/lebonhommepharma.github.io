Support

Exergy is a remaining-quota tracker for AI coding accounts. No Exergy login.

Demo meters

First launch shows labeled demo rings so you can read the UI without secrets. Turn Demo off in Settings before adding real accounts.

iCloud

Sign in to iCloud in System Settings. Exergy uses the private CloudKit container iCloud.com.lebonhommepharma.exergy. If unsigned, the app stays on-device.

OAuth

Redirect is exergy://oauth. Tokens stay on device. If a provider has no public usage percent, the ring stays empty rather than inventing zero.
