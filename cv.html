// profile

Computational pharmacologist working at the intersection of genetic algorithms and statistical mechanics. Main author of FlexAIDΔS, a genetic-algorithm docking engine that computes the full ΔG = ΔH − TΔS − the conformational entropy term included, recovering the correct binding mode where enthalpy-only scoring fails. Every result is reproducible by construction and shipped under Apache 2.0. Anti-prohibitionist; harm reduction as applied thermodynamics. Montréal.

// software & open source
FlexAIDΔS C++26 · Python · PyMOL Apache 2.0
Entropy-driven molecular docking engine. GA conformational search, Voronoi contact function, torsional ENCoM entropy, DEE torsion pruning, zero-copy GPU/OpenMP batch scoring.
Shannon C++20 · Python Apache 2.0
Entropy-collapse detector for frontier LLM agents − zero-shot evaluation-awareness and strategic-deception monitoring via the same H = −Σ pi log2 pi kernel that scores FlexAIDΔS binding.
ClusterFuck Swift · HealthKit · CareKit Apache 2.0
Multi-platform Apple biofeedback (Watch · iPhone · TV · Vision Pro). Real-time HRV entropy → Shannon Collapse Index during guided chair yoga.
NRGsuite Python · PyMOL open source
PyMOL plugin packaging the Najmanovich Research Group docking toolchain for real-time interactive docking with FlexAID.
PoseBust C++26 open source
PoseBusters-compatible geometric validation − physical-plausibility checks (bond geometry, clashes, planarity) for docked ligand poses.
// benchmarks & validation

FlexAIDΔS is validated on Astex Diverse 85 by self-docking and cross-docking with no crystal coordinates supplied, scoring the top pose by heavy-atom RMSD against the deposited ligand and by PoseBusters-style physical-plausibility checks. Shannon is validated on labelled entropy-collapse traces by detection sensitivity at fixed false-positive rate. The Astex campaign is in progress; measured results are published at thebonhomme.com/benchmark/ as they land, never before.
